## 🚀 Quick start (30 seconds)

```bash
# 1. Clone it
git clone https://github.com/v01dst/novatrend-template.git
cd novatrend-template

# 2. Run it — pick ONE:
python3 -m http.server 8000        # then open http://localhost:8000
# or
npx serve .                         # then open the printed URL
# or just double-click index.html (works, but a local server is better)
```

That's it. No `npm install`. No build. 🎉

## 🎨 Customize it (beginner exercises)

1. **Change the brand** — search for `NovaTrend` in `index.html` and replace it.
2. **Change the accent color** — edit `--acc: #FF5E35` in `style.css`. Try `#7C3AED` (purple) or `#0EA5E9` (blue).
3. **Add a product** — copy one object in the `P` array in `app.js`. The carousel updates automatically.
4. **Change the sale timer** — edit the `END = ...` line in `app.js`.
5. **Make it yours** — swap the Unsplash image URLs for your own photos.
